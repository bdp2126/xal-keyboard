# xal-keyboard
This is the Kalmyk (xal) keyboard layout that I use as a researcher, designed using [Ukulele](https://software.sil.org/ukelele/).

Installation instructions for Mac users:
- Download xal.keylayout
- Go to the "Library" folder (it's hidden by default on Macs, but if you don't know how to get there, you can open Finder, click "Go" in the top taskbar, hold option, and then "Library" should appear as an option under the option for "Home.")
- Copy or move xal.keylayout into "Keyboard Layouts"
- Log out and log back in or restart your machine
- Navigate to "keyboard" in your settings app and click "Edit" under "Text Input"
- Click the plus arrow in the bottom left-hand corner and scroll down to "Others"
- Add XAL to your keyboards! You can navigate between input sources by using the top taskbar, or by changing what the key with the globe does in the Keyboard menu

I have not tested the Windows version yet. I believe you will need to install [Microsoft Keyboard Layout Creator (MSKLC)](https://www.microsoft.com/en-us/download/details.aspx?id=102134) and use it to open xal.klc, at which point it should guide you through the keyboard installation process.

This layout is inspired heavily by [this project by sjorcindy](https://github.com/sjorcindy/xal-keyboards/tree/master).
